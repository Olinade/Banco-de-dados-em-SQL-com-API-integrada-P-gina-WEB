# Banco-de-dados-em-SQL-com-API-integrada-a-gina-WEB
Projeto integral de semestral, onde construiremos um banco de dados com uma API integrada a uma página WEB, trazendo com sigo um programa em C para geração de relatórios.

O programa será feito em 4 partes: O banco de dados em SQL; a API em linguagem ainda não definida; o programa em C; e a Página WEB para aplicação e manipulação do banco.

o Banco de dados deverá conter cerca de 4 ou 5 elementos relacionados ao tema escolhido (estoque de produtos, cadastro de clientes ETC...), e a partir da aplicação de uma API, programada pelo grupo, deve ser possível fazer a visualização e análise dos dados presentes na página construída. Junto a execução da API, deve ser possível a integração de um programa em C que realizará a análise dos dados presentes no banco, e com um comando simples de get, realizar uma análise de pendencias em cada campo de atributos de acordo com as necessidades do contexto da BD.

O projeto deve trazer solução para o contexto fictício a cerca do tema definido, através da transformação digital a partir dessa solução computacional.
